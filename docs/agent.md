# Агент и погодные данные

`agent/wind_agent` зависит только от `wind_contracts` и сторонних библиотек. Протоколы `WeatherProvider` и `Predictor` находятся в `interfaces.py`; `ForecastAgent.run(request, turbines, emit)` возвращает `ForecastResult`.

Политика фиксирована: проверить активы и дату обучения → получить погоду → проверить каждый час → рассчитать мощность → проверить результат → записать предупреждения. LLM не используется и не управляет доступностью данных.

`DemoWeather` детерминирован по turbine ID и valid time. `ArchiveWeather` выбирает самый новый допустимый запуск, затем более ранние. Снимок должен быть `verified`, `kind=forecast`, иметь непустое `availability_evidence`, `available_at <= issued_at` и точное покрытие `T+1…T+H`. При неполном новом запуске выбор предыдущего фиксируется событием `fallback`. Синтетического fallback в архивном режиме нет.

`SingleRunsAdapter` запрашивает только ECMWF, ветер 100 м в м/с, температуру в °C и направление в градусах. Проверяет единицы, UTC и длины массивов. Часы с null не интерполируются и сохраняются как пропуски покрытия. Исходный ответ и параметры запроса сохраняются в `WINDFARM_WEATHER_CACHE`. 429, 5xx и transport errors повторяются максимум три раза; паузы 1 и 2 секунды. Ошибки параметров не повторяются. Повторы пишутся в журнал backend. После исчерпания — HTTP 503.

Скачанный кандидат остаётся `unverified`, без `available_at`. Для подтверждения импортируется новая ревизия с новым ID. Поле доказательства — утверждение проверяющего, приложение не проверяет подлинность внешнего документа. `retrieved_at` никогда не используется вместо времени публикации.

По [документации Single Runs](https://open-meteo.com/en/docs/single-runs-api), проверенной 23.09.2026, `run` означает инициализацию, а расчёт и публикация происходят позже. В описании раннего ECMWF указано `IFS Cycle 49R1 hindcasts`; дата начала покрытия не доказывает пригодность для честного исторического replay. Исходные CSV не содержат независимых доказательств публикации. Данные Open-Meteo требуют [атрибуции и соблюдения условий использования](https://open-meteo.com/en/terms).

Fingerprint учитывает запрос, конфигурацию турбин, содержимое и метаданные погоды, модель и fingerprint обучающего набора. Прежние результаты не перезаписываются. Одинаковые входы возвращают прежний успешный/работающий run; ошибка допускает повторный запуск с новым ID.

```powershell
uv run python -m wind_agent.worker --run-id run-REPLACE --interval 60
```

Watcher проверяет обновления для **фиксированного времени выпуска**. Новый поздно опубликованный запуск не может менять прошлый прогноз. Для прогноза на более поздний момент нужен новый `POST /forecasts` с новым `issued_at`. Watcher не является ежедневным планировщиком и не подтверждает погоду автоматически.

# Демонстрация за несколько минут

1. `npm run dev`, открыть http://127.0.0.1:5173.
2. Оставить Synthetic demo / Demo power curve, запустить 48 часов. Показать 96 точек, DEMO, предупреждения о высоте ветра и журнал агента.
3. Скачать CSV. Нажать «Проверить новые входы»: ID не изменится.
4. В «Данные и модели» импортировать `examples/observations.demo.csv`, включив «Искусственные данные» и указав происхождение. Обучить binned curve с cutoff 30.01.2026 23:00 UTC. Она остаётся DEMO.
5. Вернуться к прогнозу, выбрать модель. Запустить replay с preset февраля. Метрики отсутствуют без фактов, покрытие показано явно.
6. В «Архив погоды» показать координаты, незаданные номинал/высоту и статусы снимков. Archive без проверенных снимков возвращает понятную ошибку.
7. Показать `artifacts/validation.json` — отдельную проверку persistence на реальной SCADA до февраля. Не смешивать её с demo replay.

Автоматизированный эквивалент: `uv run python scripts/smoke_demo.py`. Он также проверяет работу frontend proxy и создаёт февральские demo-артефакты.

Что не заявляем: что погодный hindcast доказывает историческую доступность; что synthetic прогноз имеет конкурсную точность; что есть факты за февраль; что квантили калиброваны; что нормализованная мощность известна в MW.
